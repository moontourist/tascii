A minimalist ASCII to-do list for Chrome's side panel.

Click the toolbar icon and your lists are already there. Stack them in tiles, cross things off with a little [x] spin, and run the whole thing from the keyboard.

[ install ] [ source on github ]

Free and open source. Needs Chrome 123 or newer.

private

Your tasks stay in your browser.

No account, no tracking, no network requests. tascii asks for two permissions, the side panel and local storage, so it can't see the pages you visit.
